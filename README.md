# ВКР: экосистема представления РИД Сеченовского университета

Исследовательский проект по разработке прототипа веб-каталога результатов интеллектуальной деятельности (РИД), связанных с научно-исследовательскими проектами Сеченовского университета.

## Цель

Создать и оценить прототип удобного публичного представления сведений о РИД: структурированные карточки разработок, поиск, фильтрация и связи с научными проектами. Проект не является официальным сервисом университета.

## Основные этапы

1. Подготовка исследования.
2. Обзор литературы и существующих цифровых решений.
3. Исследование пользователей и сбор требований.
4. Проектирование структуры, модели данных и интерфейса.
5. Разработка минимально жизнеспособного прототипа (MVP).
6. Тестирование и оформление результатов ВКР.

## Текущее состояние

Подготовлена концепция проекта и выполнен предварительный анализ открытых ресурсов Сеченовского университета. Требования, интерфейс, прототип и пользовательское тестирование находятся на последующих этапах. Подробности — в [статус-отчёте](STATUS_REPORT.md).

> Учебный проект ВКР. Все сведения о разработках, используемые в будущем прототипе, должны быть разрешены к публичному размещению.
